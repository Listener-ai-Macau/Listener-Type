# Code of Conduct

## Our standard

Listener Type is maintained as a practical, respectful open-source project.
Contributors are expected to be constructive, patient, and specific when
discussing code, product behavior, accessibility, privacy, or hardware.

Unacceptable behavior includes harassment, discrimination, threats, doxxing,
sexualized conduct, deliberate disruption, and publishing another person's
private information or credentials.

## Enforcement

Report a conduct concern privately to the repository maintainers through the
repository's GitHub private contact or Security Advisory channel. Do not put
private details, personal data, recordings, transcripts, or credentials in a
public issue. Maintainers may remove comments, close discussions, or restrict
participation when needed to keep the project safe and useful.

This policy applies to issues, pull requests, code review, discussions, and
project-managed community spaces.
