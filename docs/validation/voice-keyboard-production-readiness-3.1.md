## Scope

This step prepares the Windows installer deliverable for the Voice Keyboard
first-run path. It records the generated Windows bundle artifacts, version,
hashes, WebView2 policy, signing policy, first-run OOBE entry, and diagnostic
export entry.

Clean Windows manual installation, real user OOBE timing, and factory-device
rounds remain deferred to plan steps 3.5 and 5.1. This step only proves the
deliverable bundle can be built and that the first-run/diagnostic paths are
present in the product and documentation.

## WebView2 And Signing Policy

- `src-tauri/tauri.conf.json` sets
  `bundle.windows.webviewInstallMode.type=downloadBootstrapper` with
  `silent=true`.
- `docs/platform/windows-build.md` documents online WebView2 Evergreen Runtime
  bootstrap and the offline/factory alternative.
- `docs/platform/windows-build.md` and `docs/quickstart/installation.md`
  document that public Windows installers must be Authenticode-signed.
  Unsigned builds are internal-test only and must be published with SHA256 plus
  an unknown-publisher/SmartScreen warning.
