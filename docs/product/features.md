# Listener 能做什么（1.0.5）

Listener 是一套桌面语音输入：说话，文字出现在当前光标。
软件是 Listener Type，设备是 Listener 语音键盘。可以只用电脑麦克风试用；配上键盘后，开始、停止和状态都在手上完成。

它不是会后录音笔，也不是「说完自动写成完美文章」的写作助手。
1.0.5 交付的是**每天能用的输入闭环**。主人声纹在更多人、更远距离下的稳定性，以及真人多人同时说话的泛化，属于 1.0.6。

逐步操作见 [使用说明](../USAGE.md)。录音停顿和旁人说话见 [录音会话](../features/recording-session-guide.md)。

## 怎么用

```text
把光标放进输入框
    → 按右 Ctrl，或按键盘上的 EC11
    → 说话
    → 再按一次
    → 文字回到光标；插不进去时留在剪贴板
```

电脑麦克风和 Listener 键盘走同一条整理、插入路径。完整硬件音频以 Windows 为主。

## 功能一览

| 你要做的事 | 1.0.5 给你什么 | 入口 |
| --- | --- | --- |
| 把话写进当前窗口 | 快捷键或 EC11 开始/停止，结果插入光标 | 右 Ctrl / EC11 |
| 看现在进行到哪一步 | 屏幕胶囊 + 设备灯 | 胶囊；PWR / BLE / REC / AI |
| 不用手碰电脑开始录 | 唤醒词「开始录音」，可选声纹 | 设置 → 录音 |
| 同一段话换语气 | Raw / Light / Structured / Formal / 翻译 | 设置 → 录音 / 风格 / 翻译 |
| 专有名词少认错 | 本机词库作为热词和润色提示 | 词库页 |
| 旁人声音少写进正文 | 受控环境下的主人前缀保护 | 录音会话说明 |
| 键和灯按自己习惯 | 四键 + 旋钮动作、亮度、低功耗 | 设置 → 设备 |
| 服务自己掌控 | 自备 ASR/LLM Key，或用本机识别 | 设置 → Provider / 高级 |
| 配对乱了能修好 | 设备恢复，不需要开发工具 | 设置 → 关于 → 设备恢复 |

## 说完，写进去

### 在任意输入框听写

把光标放进记事本、浏览器、聊天框或编辑器，按一次开始，再按一次停止。
文字插入原来的位置。目标应用拒绝自动输入时，内容留在剪贴板，提示你手动粘贴。

默认是切换式，不是按住说话。Windows 默认右 Ctrl，macOS 默认右 Option。
录音中按 `Esc` 取消，不会插入半截字。

### 电脑麦克风或 Listener 键盘

没有设备时，在「设置 → 录音」把输入源改成麦克风即可试用。
有设备时走 Listener BLE，配对名是 `listener`。完整板端音频路径以 Windows 为主。

### 胶囊告诉你进行到哪

| 状态 | 含义 | 你要做的 |
| --- | --- | --- |
| Ready | 可以开始 | 按快捷键或 EC11 |
| Recording | 正在收音 | 说完再按一次 |
| Transferring / Transcribing | 音频在送去识别 | 等，不要连按 |
| Processing | 在选最终文本、整理 | 等 Done |
| Done | 已插入或已在剪贴板 | 看光标处的字 |
| Error | 这一次失败了 | 按提示重试，或导出诊断包 |
| Recovery | 需要重新配对或重连 | 删掉 Windows 里的 `listener` 再配对 |

胶囊可以关掉，关掉只影响提示，不影响录音。

## 手上的键盘

### EC11 旋钮

开机键。开机后单击默认开始或停止录音。
双击重置蓝牙配对。旋转默认调电脑音量，可在设置里改成亮度或关掉。

### KEY1–KEY4

自定义动作。未配置时走安全兜底，不会乱打字。
出厂常见：KEY3 粘贴。具体动作以「设置 → 设备」为准。

### 灯

| 灯 | 平时表示 |
| --- | --- |
| PWR | 电源和电池。充电中偏白，电量用绿/黄/红 |
| BLE | 蓝牙。配对或重连会闪，Type 就绪后稳定蓝 |
| REC | 设备确实在采音 |
| AI | 停止后传输或主机正在处理 |
| OK | 成功确认，或升级进行中 |
| WARN | 需要处理的错误，不是装饰 |

低功耗时灭灯是预期行为，不代表设备坏了。

### 配对和恢复

在 Type 里点「开始配对」，Windows 蓝牙选 `listener`，再点「检查连接」。
搜不到或反复配对时：设置 → 关于 → 设备恢复，删掉旧的 `listener`，回到录音设置重配。
这条路径不需要串口、ESP-IDF 或开发工具。

## 按你的方式整理

| 模式 | 适合 | 行为 |
| --- | --- | --- |
| Raw | 原话、代码、会议记录 | 尽量保持原词和顺序 |
| Light | 聊天、备忘 | 去口癖、补标点，不改事实 |
| Structured | 需求、任务、prompt | 按主题整理成结构 |
| Formal | 邮件、工作沟通 | 更清楚正式，不编造内容 |
| Translation | 要另一种语言 | 按目标语言翻译后再插入 |

云端润色不可用时，留下原始转写。Raw 和本机识别可以不调用大模型。

词库给人名、产品名、缩写。风格包可复制内置风格，导出导入 ZIP。
远程 Marketplace 默认可能是空的，这是本地优先，不代表本机风格坏了。

翻译快捷键默认 Shift，只在翻译页选了目标语言后生效；失败回退原文。

## 尽量只留下你的话

打开「检测到人声后自动开始」后，设备先等唤醒词，默认是「开始录音」。
唤醒词本身不是正文。环境噪声不会单独开录。

可以按引导把当前唤醒词说三遍，完成本机声纹。没有声纹时，能正确说唤醒词的人可能触发。
声纹是输入保护，不是登录或身份认证。改唤醒词后必须重录。

1.0.5 在受控环境里会：

- 主人停顿后再说，仍算同一段
- 电脑播放的旁人内容不应单独写入正文，也不应单独拖长结束
- 两人同时说时，优先保住已经确认的主人前缀，结果要人工看一眼

这不是任意房间、距离和口音下的 100% 分离。只看预览、不看最终插入，不能算成功。

## 本地优先

设置、词库、风格、历史、可选调试录音默认在本机。
Provider Key 进系统凭据库。应用不内置开发者 Key。
云端 ASR/LLM 用你自己的账号；也可以用 Windows 本机 Whisper。本机识别不消耗云端时长，中文效果通常不如火山引擎。

诊断包从「设置 → 关于」导出，用于看连接和会话状态，不含 Key、录音和转写正文。

## 1.0.5 明确不承诺的

- 任何环境、任何人声重叠都滤干净
- 把声纹当门禁或法律身份证明
- 正式安装包注册成系统输入法
- 未配置后端时的远程风格市场
- macOS / Linux 上与 Windows 同等的 Listener BLE 音频验收

这些不是缺陷列表，是当前版本边界。需要逐步操作时回到 [USAGE.md](../USAGE.md)。
