# Demo 内容包

状态：implemented
日期：2026-05-20

## 目标

首次体验在无设备、无 API Key 或断网时仍能完成一次可理解的试玩，但必须明确标识为 Demo，不把离线结果伪装成真实录音或真实云端润色成功。

## 入口

- 概览页 Quick Start 的“先看 Demo”。
- 设置提供商失败路径的“打开 Demo”。
- Listener BLE 无设备/测试失败路径的“打开 Demo”。

这些入口只打开概览页的 Demo 卡片，不写入凭据、模型、输入源或设备配置。

## 玩法

| 玩法 | 输入样例 | 期望输出风格 | 失败兜底 |
| --- | --- | --- | --- |
| AI 焦虑吐槽 | “AI 每天都在更新，像一列不等人的车。” | 半吐槽、半整理，表达 AI 时代的压力和好奇，不给心理治疗建议。 | 无设备、无网络或无 Key 时展示内置样例，标注 Demo，不写真实配置。 |
| 轻量角色回应 | “假装你是桌面小助手，帮我用一句轻松的话回应。” | 温和、简短、有陪伴感，但只作为娱乐和表达，不冒充真人关系、儿童玩具或专业建议。 | 离线时使用固定角色回应，失败后可换玩法、试麦克风或稍后配置云端服务。 |
| 语音转表达润色 | “这版先以体验闭环为主，包装和量产细节下一轮确认。” | 把口语整理成清楚、可发送的文字，保留原意，不虚构事实。 | 云端不可用时展示本地样例，并提示真实语音转换仍需要可用录音路径或本地 ASR。 |

## 边界

- Demo 结果只来自内置样例，不调用真实 ASR/LLM。
- Demo 不保存 API Key，不切换模型，不修改录音输入源。
- Demo 不隐藏生产路径失败：无设备、无 Key、断网等错误仍在原入口展示短文案和下一步动作。
- 内容口径只聚焦娱乐、表达和轻量创作，不承诺心理治疗、疗效、儿童玩具属性或专业建议。

## 验收

- 无设备/无 Key 状态下能打开 Demo。
- 至少能完成一个玩法：选择玩法，看到输入样例、输出样例、输出风格和失败兜底。
- 切换玩法不会写入真实配置。
