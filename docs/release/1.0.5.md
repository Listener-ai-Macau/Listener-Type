# Listener 1.0.5

这是现在可以天天用的版本。

按一下，说话，再按一下。文字出现在你正在用的输入框里。聊天、邮件、文档、代码注释，不必先录进另一个 App 再复制。目标窗口不让自动输入时，字留在剪贴板。

软件是 [Listener Type](https://github.com/Listener-ai-Macau/Listener-Type)。键盘固件是 [Listener Firmware](https://github.com/Listener-ai-Macau/Listener-Firmware)。两个包一起用。还没买键盘，先用电脑麦克风。

完整功能：[产品功能](../product/features.md)  
怎么装、怎么配对：[使用说明](../USAGE.md) · [语音键盘手册](../quickstart/voice-keyboard-readme.md)

## 相对 1.0.4

1.0.4 已经能听写。1.0.5 把日常录音收成可以卖的基线：

- 说完「开始录音」接着讲，开头还在，仍认你
- 胶囊上先跳出来的字只是预览，不会把半截写进正文
- 中间停一下，不会马上交卷；说完大约一秒结束，也可以再按一次停
- 轻轻说唤醒词，开头留得住；键盘灯能对上你在做的事

## 这版不承诺

更远、更吵的房间里的声纹，以及旁边有人同时说话，放到 **1.0.6**。一次在受控环境里通过，不等于你家客厅也一样干净。

声纹只用来少写下别人的话，不是门锁，也不是身份证明。安装包不会变成系统输入法。完整键盘音频以 Windows 为主；Mac 和 Linux 可以先用麦克风和快捷键。

## 装完试一句

1. 双击 Type 的 MSI，从开始菜单打开。
2. 有键盘：点「开始配对」，Windows 蓝牙选 `listener`，再点「检查连接」。键盘在 Type 里升级。
3. 没有键盘：设置 → 录音 → 输入源选麦克风。
4. 光标放进记事本，按右 Ctrl（有键盘按旋钮），说话，再按一次。看光标处的字。

# Listener 1.0.5

This is the release you can use every day.

Press, speak, press again. Text lands in the field you were already using — chat, mail, docs, comments — without a recorder app in between. If the target window blocks insert, the words stay on the clipboard.

The app is [Listener Type](https://github.com/Listener-ai-Macau/Listener-Type). Keyboard firmware is [Listener Firmware](https://github.com/Listener-ai-Macau/Listener-Firmware). Use them together. No keyboard yet: start with the computer microphone.

Catalog: [product features](../product/features.md)  
Install and pairing: [usage](../USAGE.md) · [keyboard handbook](../quickstart/voice-keyboard-readme.md)

## Versus 1.0.4

1.0.4 could already dictate. 1.0.5 is the daily-driver baseline:

- After “开始录音”, the start of what you say is still there, and it still knows it is you
- Words that appear first on the capsule are a preview; they do not become a half-finished insert
- A pause in the middle does not submit. About a second after you finish, it ends — or press again
- A quiet wake phrase keeps its beginning. The lights match what you are doing

## Not in this release

Farther rooms, noisier rooms, and someone talking at the same time are **1.0.6**. A pass in a controlled room is not “works in your living room.”

Voiceprint is there to keep other speech out of the body text. It is not a lock and not an ID. The installer does not become a system IME. Full keyboard audio is Windows-first; Mac and Linux can use the microphone and hotkey first.
