# 出厂 QA Checklist

> 版本：v1.0.0  
> 适用产品：Listener Type  
> 最后更新：2026-05-21  
> 执行人：非固件开发者（无需看串口日志）  

---

## 如何使用本 Checklist

1. 在右侧「结果」列勾选 **通过 / 失败 / 不适用**。  
2. 在「备注」列记录异常现象或截图编号。  
3. 全部完成后在底部签字并记录日期。  
4. 任何 **失败** 项必须对应一个修复步骤编号（见「对应修复」列）。

## 四、KEY1 语音键功能

| # | 检查项 | 方法 | 通过标准 | 结果 | 备注 | 对应修复 |
|---|--------|------|----------|------|------|----------|
| K1 | 按键触发录音 | 短按 KEY1（GPIO35/EC11-KEY）一次 | 桌面端胶囊进入录音状态（红色/动画） | ☐ | | |
| K2 | 按键停止录音 | 再次短按 KEY1 | 胶囊停止录音，进入转写/处理状态 | ☐ | | |
| K3 | 录音时长匹配 | 按住 KEY1 3 秒后松开 | 导出的 WAV 时长约 3 秒（±0.5 秒容差） | ☐ | | |
| K4 | 快速连按 | 快速按 KEY1 两次（<1 秒间隔） | 行为可预期：第二次按下视为停止，不崩溃 | ☐ | | |
| K5 | 长按行为 | 按住 KEY1 超过 10 秒 | 录音持续进行，松开后正常停止；无崩溃 | ☐ | | |
| K6 | 首次按键 | 设备重启后第一次按 KEY1 | 正常触发录音，无首次按键失效 | ☐ | | |

## 五、取消与恢复功能

| # | 检查项 | 方法 | 通过标准 | 结果 | 备注 | 对应修复 |
|---|--------|------|----------|------|------|----------|
| C1 | 录音中取消 | 按下 KEY1 开始录音，按桌面端 `Esc` 或设备取消键 | 录音立即停止，胶囊回到空闲状态 | ☐ | | |
| C2 | 处理中取消 | 松开 KEY1 后、文字插入前按 `Esc` | 转写/润色中断，不插入任何文字 | ☐ | | |
| C3 | 恢复出厂设置 | 长按特定组合键（如 BOOT+KEY1）或桌面端命令 | 设备清除配对信息，重启后回到未配对状态 | ☐ | | |
| C4 | 恢复后重配对 | 执行恢复后重新配对 | 与新桌面端正常配对，功能完整 | ☐ | | |
