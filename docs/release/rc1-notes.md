## In this app update

Selected translation settings fold after success so that the result and Save stay in view. The source, target and method remain visible in the summary; reopen it without losing text or selections. A failure expands the settings for recovery. The Windows Overview also opens the existing Chinese ↔ English local text workspace directly. Ordinary text entry remains separate and retains typed input. The README and existing guides explain this no-hardware/no-key starting route.

The original172 presale and assumed-owned aftersale AI users could translate and save their own text; the latter also reopened the saved draft. Both found settings pushed results and saving down the screen. This update addresses that common usability issue. Their opinions are not real purchases or physical qualification; no natural173 customer result is claimed.

## Before using

US$49 is the hardware price. Type is free and open source. Cloud recognition and optional cloud text services require preparation and separate usage charges; this release does not provide a ready-to-use official account or allowance. Optional Windows Chinese ↔ English local text translation needs a one-time component download and has no translation API fee. It does not configure speech recognition. USB flashing and Bluetooth OTA use the same firmware ZIP.

Translation models, recognition, wake/end logic and Bluetooth firmware are unchanged. Local translations still need review and may misstate a relation or use awkward wording. Strong background-speech separation remains incomplete; older intermittent ending and arbitrary-editor scopes remain separately open. RC1 and limited software checks are not a claim of universal quality, all-feature physical/long-term reliability or a real order.
