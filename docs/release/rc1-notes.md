## In this app update

The overview is now a recoverable getting-started guide. Choose **Skip and don’t show again** to hide its main navigation entry and start on History on subsequent launches. **Getting started** at the bottom left opens it again without restoring a permanent tab. If Type cannot save the choice, it explicitly says the guide may return.

Typed text, saved drafts, recorded-audio transcription and key-layout utilities remain under **Tools → More tools**, collapsed by default. Saved-draft and bundled-help directions follow the new route. This is an interface update; it does not change recognition services, recording decisions or Bluetooth parameters.

## Before using

US$49 is the hardware price. Type is free and open source. Recognition and optional text services require preparation and separate usage charges; this release does not provide a ready-to-use official cloud account or allowance. USB flashing and Bluetooth OTA use the same firmware ZIP.

RC1 is a prerelease. Strong background-speech separation remains incomplete. Older intermittent early-ending and arbitrary target-field scopes remain open; software checks do not establish physical/long-term reliability or purchase value. Recognition, wake/end logic and Bluetooth firmware are unchanged in this UI update.
