## In this app update

New installations start with all five computer shortcuts unassigned: recording, translation, question window, previous style and opening Listener Type. Record a shortcut only when you need it, or clear an assigned shortcut in Settings. Updates preserve existing saved bindings; device controls are unchanged. Explicit result handoffs retain the first input with the final saved draft. Continuing a saved draft preserves its attached original when saving a new version; the existing v1 file format and immutable older records are retained. In a translation/refinement session, use Retranslate from the original to revisit the full pre-translation input and explicitly submit to your own cloud service after reviewing the target and fees. Return restores your edited translation; opening the route sends nothing. Existing WAV import is now visible in Overview and as a Tools card. No model, speech backend or firmware change.

## Before using

US$49 is the hardware price. Type is free and open source. Recognition and optional text services require preparation and separate usage charges; this release does not provide a ready-to-use official cloud account or allowance. USB flashing and Bluetooth OTA use the same firmware ZIP.

Light offline translation is a useful editable draft, not guaranteed exact translation. Important dates, quantities, negation and terminology need review. This accepted quality scope does not remove the open strong-background/early-ending, actual global/physical/cross-PC/long-term or original brownout evidence gaps. Optional enhanced CPU support does not qualify all computers. No new firmware flash is required. The first input and final saved result are retained; intermediate versions need explicit separate saves. Previously saved drafts cannot recover source text that was never saved. Source retranslation does not guarantee better meaning and cloud charges still apply. The native private test station cannot qualify Windows interactive global registration or triggering; that existing acceptance gap remains open.
