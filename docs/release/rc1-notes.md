## In this app update

Text requests now show elapsed waiting time, without claiming a percentage or estimated finish. Chinese-source confirmation sits beside the source-language selector. Save confirmations, empty recording History and offline help use the visible saved-draft names and point to History → Saved drafts. Original inputs, separate edited versions, explicit service charges, cancellation, recording recovery and opt-in shortcuts are retained. Firmware38 and the existing audio/translation backend are unchanged.

Light CPU translation is an editable draft and may mistranslate or omit meaning; review it against the original. Buffered request timing is elapsed wait only. Existing source-owned voice/tail/recovery fixes remain, while historical intermittent GATT timeout and brownout trigger causes are not declared solved. Prior live/physical results retain their original scope; remaining global/target-app, second-PC and long-term combinations are not universally qualified.
