## Find and identify your saved drafts

Open **History → Saved drafts**, edit **Draft name**, then use **Save name** or Enter. Your name appears first in the list. Renaming keeps the text, attached original, record ID and saved time unchanged. It does not create another draft or make a service request. Failed saves retain the name edit; a conflicting name requires a refresh, and a deleted target is not replaced with another draft.

New translation drafts start with labels for actual local/cloud processing and direct manual edits. You can replace the generated name. Existing draft names are retained; older processing origins are not inferred. Editing the body still uses **Edit a copy**, preserving the original. Cloud translation options now show the target and existing service without asking for a source selector that is not available. The five UI languages and guides are updated.

This batch follows complete independent build197 presale and assumed-owned aftersale sessions. Both completed their own message/edit/save/retrieval purposes and independently wanted clearer draft naming or source/version cues. Their mistranslations and hardware deferral remain in the original reports. This update does not fix model translation semantics or establish a purchase.

## Voice questions retained from build197

With Listener connected and speech/answer services configured, say **“开始提问”** followed by your question. The resizable card at the recording capsule position previews recognized words. Pausing speech can finish capture and request an answer; **Finish and ask** remains available. **“开始录音”** still starts dictation, and the computer-microphone button route remains. Questions and answers are not automatically pasted into another app or clipboard. Answer requests include one current local timestamp; model facts still need review. Existing capture ownership, enrollment binding and one transient retained-audio recovery are unchanged in198.
