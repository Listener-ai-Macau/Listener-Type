## In this app update

**Settings → Help center** now opens inside Type. **About → Docs** opens the same guide. Basic setup, hardware and service costs, result recovery, data handling and current limits can be read without opening GitHub. Help is bundled in English, Simplified and Traditional Chinese, Japanese and Korean.

The guide’s input and provider buttons open the existing settings sections. Reading help does not start recording, text processing, a model download or a device write. The full GitHub manual remains an explicit online link. This does not make cloud recognition or text processing work offline.

The MSI download label on the product pages now matches this build. Existing text drafting, saved phrases, recording settings and Firmware33 are retained. USB flashing and Bluetooth OTA use the same firmware ZIP.

## Before using

US$49 is the hardware price. Type is free and open source. Recognition and optional text services require preparation and have separate usage charges; this release does not include a ready-to-use official cloud account or allowance. Review important text.

RC1 is a prerelease. Strong background speech separation remains incomplete and intermittent early-close cases remain under review. This update does not qualify new live-wake, automatic-ending, global-input or physical-hardware behavior. It has not been installed over the daily Type instance as part of this publication.
