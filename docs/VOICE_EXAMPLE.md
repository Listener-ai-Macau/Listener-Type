# Recorded software example · 25 seconds

**[Watch / download the 25-second example](assets/voice-example/voice-example.mp4)** · [Listen to the 11.5-second source](assets/voice-example/voice-sample.wav) · [简体中文](VOICE_EXAMPLE.zh-CN.md)

One short message becomes text in Type. The English voice was generated locally with Microsoft Zira, then processed by the released Windows Type build92 with configured Volcengine recognition. The actual transcript was subsequently submitted to Light polish using the normal text-trial screen and a configured DeepSeek service. You can view this saved example without an account or installation.

## Recognition result — Original text

> Hi, Sam. Let's meet on Thursday at 3.  I'll send the notes before lunch.  Please keep the budget at 50 dollars, and tell me if the time needs to change.

## Optional Light polish — actual returned result

> Hi Sam, let's meet on Thursday at 3. I'll send the notes before lunch. Please keep the budget at 50 dollars, and tell me if the time needs to change.

The meeting time, notes before lunch and fifty-dollar budget are present in this particular result. Review your own output before sending it.

## What is shown

The clip combines the source audio and screenshots captured from the actual run. It is an edited presentation, not continuous screen recording. Recognition used a prerecorded file entry; polishing was a separate text-trial action. [Full recognition screen](assets/voice-example/type92-recognition.png) · [Full polishing screen](assets/voice-example/type92-light.png).

Live microphone capture, Bluetooth, pressing the device, automatic insertion into another app and performance in noise are not demonstrated here. One clean synthetic sample cannot establish general recognition quality or real-time latency.

Type is free and open source; US$49 is the Listener hardware price. The services in this example were already configured and have separate provider charges. No ready-to-use official account or cloud allowance is included in the current release.
