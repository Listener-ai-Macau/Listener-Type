# Listener Type 使用说明（当前 RC1）

这份说明介绍安装、快捷键与设置；产品概览见[主页](../README.zh-CN.md)。

本指南对应当前 `v1.0.6-rc1` 候选版。请从[当前软件发布页](https://github.com/Listener-ai-Macau/Listener-Type/releases/tag/v1.0.6-rc1)
下载 MSI，并以该页的构建号、SHA-256、已知限制为准；硬件使用配套的[固件 ZIP](https://github.com/Listener-ai-Macau/Listener-Firmware/releases/tag/v1.0.6-rc1)。
早期 1.0.5 说明保留在[历史发布记录](release/1.0.5.md)，不作为当前设置基线。
RC1 不保证在任何环境下完全过滤旁人声音；强干扰下请复核正文，并在需要时手动结束。

## 没有 API 密钥，从哪里开始？

| 你想先做什么 | 当前可用路径 | 还需要什么 |
| --- | --- | --- |
| 先翻译一段中英文字 | 「概览 → 本机中英翻译」；确认原文和译文语言、按需准备组件，翻译后检查或编辑，再保存成稿 | 64位Windows；首次下载组件需联网和磁盘空间。无需硬件／云Key，无逐次翻译API费用；不等于语音识别也已配置 |
| 先把说的话转成文字 | Windows 本地识别设置中准备 Foundry Local 运行时和 Whisper 模型；在「设置 → 录音」选择电脑麦克风，以默认原文（Raw）试录 | 首次下载需要联网与磁盘空间；运行会使用内存，速度取决于电脑。无需云端识别密钥 |
| 自动去口癖、整理长消息 | 在识别之外，配置可用的文字服务，再选 Light / Structured / Formal | 本地语音识别只负责转写，不会同时提供这些整理服务；云端文字服务费用由提供方决定 |
| 使用已有云端识别账号 | 在提供商设置填写该服务要求的凭据、模型及地址，先用 Raw | 识别额度、地区可用性及费用以该提供方为准 |

**内置风格包可在本机查看、编辑和导入导出，不代表 Light 能离线生成正文。** 默认 Raw 不需要文字服务；自定义 Raw 若加入需要服务的处理，以风格卡片和试用窗口显示的实际需求为准。服务显示“已配置”也不代表仍有额度或网络调用一定成功。

### 只翻译文字，不先配置语音识别

从「概览 → 本机中英翻译」直接进入文字工作区。当前本机包支持中英互译，选择不同的原文和目标语言；含汉字的输入可明确确认中文，但字符提示不是通用语言识别。首次按“下载组件”准备所需语言方向与运行组件：初次中译英下载约113 MB，解包后的磁盘占用另计。选择语言本身不会下载。译文仍需检查，可能生硬或误译；可直接编辑，明确保存后从「历史 → 已保存成稿」找回。完成翻译会收起已选设置，可再展开，失败时自动展开。此窗口的选择不改变日常录音或语音翻译设置。

在「历史 → 已保存成稿」可为选中的稿件修改“成稿名称”，点“保存名称”或按 Enter 确认。改名不改变正文、随附原文、记录身份或保存时间；同一分钟保存的相似稿件可以用自己的名称区分。新译稿的默认名称区分本机／云端及手动修改，旧稿名称保留。编辑正文仍通过“编辑副本”另存，原稿不被覆盖；不需要的稿件可明确选择后删除。

### Windows 无密钥语音识别：在软件里怎么点

1. 打开 Type 的「设置 → 提供商」，在语音识别区域点击 **“准备本地识别”**。不用先选一个云端厂商，也不用填写 Key。
2. 在 **“Windows Foundry Local Whisper”** 页面保留默认 **Whisper Small（whisper-small）**。页面另有 Base / Tiny，可减少下载，但识别效果可能下降。
3. 查看页面的模型大小与运行组件状态。大小来自当前服务目录；显示“未知”时，表示尚未取得大小，不是零下载。总磁盘占用还包括运行组件和解包文件，不能只按模型大小计算。
4. 点击 **“准备并使用本地识别”**，等待下载、加载和启用完成。取消或失败会保留原识别服务；“仅下载 / 加载”本身不会切换服务。看到已加载模型和当前启用状态后，再开始录音。
5. 回到「设置 → 录音」，选择电脑麦克风；在风格页保留默认原文（Raw）。光标放进可编辑输入框，按 Right Ctrl 说一句，再按一次结束并复核。

这条路径不包含自动整理，也不是不用下载即可立即开口。下载前可按页面当时的大小选择是否继续；本指南不把尚未取得的体积或运行内存写成固定承诺。

## 先判断你要用哪条路径

Listener Type 有两种输入源：

- **电脑麦克风**：不需要 Listener 硬件，适合先试用。打开「设置 → 录音 →
  输入源」，选择「麦克风」。
- **Listener BLE**：Windows 上的完整硬件音频路径。配对名默认是 `listener`，
  在「设置 → 设备」完成配对，再在「设置 → 录音」检查 BLE 音频通路。

默认偏好是 Listener BLE；如果用户明确改过输入源，应用会保留该选择。没有设备
时切换为电脑麦克风即可，不需要修改配置文件。

## 安装和首次启动

### Windows

1. 从 [GitHub Releases](https://github.com/Listener-ai-Macau/Listener-Type/releases)
   下载当前 Windows `.msi` 并安装；用同一发布页正文中的 SHA-256 表格核对文件。
   文件名和校验值以该次发布附件为准。
2. 从开始菜单启动 Listener Type；首次启动允许麦克风访问。
3. 使用硬件时按「开始配对」，在 Windows 蓝牙设置中选择 `listener`，回到
   应用后点击「检查连接」。
4. 首次使用建议在记事本中完成一条短句，确认录音、转写和插入都正常。

安装程序会使用 Tauri/WebView2。联网时缺少 WebView2 会自动安装 Evergreen
Runtime；离线电脑应预先安装 WebView2。当前正式安装包不注册旧版 TSF 输入法；
Windows 文字插入会按运行时能力选择原生路径，失败时回退到粘贴/剪贴板。

### macOS 和 Linux

- macOS 12+：当前只发布 Windows 安装包，macOS 需要按仓库 README 从源码构建；
  运行后允许「麦克风」和「辅助功能」，授权辅助功能后完全退出并重新打开应用。
  macOS 正式支持（含 Apple Speech 识别与安装包）在路线图中。
- Linux：X11 使用 best-effort 全局热键；Wayland 不允许应用直接监听全局按键，
  请在桌面环境中绑定下方 CLI 命令。Listener BLE 的完整验证仍以 Windows 为主。

## 最短成功路径

1. 把光标放进任意文本框（记事本、浏览器、聊天框或编辑器）。
2. 按一次录音快捷键，胶囊出现；是否逐段显示和写入取决于所选服务及模式。
3. 正常说话；自动结束取决于已保存的设置和会话状态，需要时可手动结束。
4. 再按一次同一快捷键，胶囊转为处理状态（识别、整理、翻译）。
5. 处理完成后，文字会插入原来的光标位置；如果目标应用拒绝自动输入，文字会
   保留在剪贴板并提示手动粘贴。

录音期间按电脑键盘 `Esc` 会取消当前会话，不会插入半截文字。胶囊可以在「设置
→ 录音 → 显示胶囊」关闭，但关闭只影响提示，不会关闭录音功能。

想了解主人自然停顿、旁人/电脑播放干扰、自动结束和最终文本如何衔接，请看
[录音会话与干扰处理说明](features/recording-session-guide.md)。

## 录音快捷键

手动录音默认使用 **Toggle（切换式）**：按一次开始，按一次停止。当前
默认键由平台决定：

| 平台 | 默认键 | 可选方式 |
| --- | --- | --- |
| Windows | 右 Ctrl（Right Control） | 右 Alt、左 Ctrl、右 Win、 自定义组合键 |
| macOS | 右 Option（Right Option） | 左/右 Option、左右 Control、右 Command、Fn、自定义组合键 |
| Linux/X11 | 右 Alt（best-effort） | 右 Ctrl、左 Ctrl、自定义组合键 |

在「设置 → 快捷键」可以录制自定义组合键。录制时一次按下完整组合；保存后
回到「设置 → 权限」确认全局 hook 状态。应用内的“按住说话”不是当前
的默认路径，若界面显示不可用，请使用 Toggle。

其它内置快捷键：

| 功能 | 默认组合（Windows / Linux） | 默认组合（macOS） |
| --- | --- | --- |
| 划词问答开关 | Ctrl+Shift+; | Cmd+Shift+; |
| 切换上一次风格 | Ctrl+Shift+S | Cmd+Shift+S |
| 打开 Listener Type | Ctrl+Shift+O | Cmd+Shift+O |
| 翻译触发 | Shift | Shift |

翻译快捷键只在「翻译」页设置了目标语言时生效；按一次即可标记本次录音走翻译，
不需要一直按住。

## 自动唤醒和主人声纹

在「设置 → 设备」检查自动开始与当前唤醒词，并确认写入成功。默认唤醒词是
**“开始录音”**；自动唤醒需 Listener BLE 音频就绪。噪声、距离和普通讲话仍可能影响唤醒。
当前自动开始／结束默认开启，以设备读取结果为准；需要时可手动结束或关闭自动开始。

点击「录制声纹」，按引导在平时使用的距离自然说三遍当前唤醒词（约 9 秒），每次等下一步提示。
完成后保留本机受保护模板，不保留原始样本录音。修改唤醒词后应重新登记。

没有声纹时，任何正确说出唤醒词的人都可能触发。声纹用于协助优先保留本人的语音；
旁人或外放仍可能混入正文、影响自动结束。它不是身份认证，不能保证多人同说时只留下本人。
噪声、距离或设备被遮挡时请靠近并复核文字。删除声纹不会关闭语音唤醒，需单独关闭自动开始。

启用唤醒时，完整录音会话开始前也可能向电脑发送候选音频；REC 灯灭不代表麦克风完全关闭。

## 输出模式

### 轻度润色和正式表达怎么选

轻度润色保留聊天语气，整理口癖、标点和顺序；正式表达侧重克制、完整的工作沟通措辞，不自动扩成带主题、落款和客套的邮件。原文已经清楚的短消息，两者可能变化很小；正式不意味着必须改得更多。姓名、时间、提议和承诺的确定程度都应保留，例如「可以发」不能变成「一定发」，提议改期不能变成已经确认。

可从「主页 → 文字试用」用自己的非敏感草稿比较保存的风格，试用不激活风格、不开始录音、不写历史。需要带走结果时点「复制结果」，等「已复制」再粘贴；查看保存示例只是看说明，不是自己的实时处理结果。


在「设置 → 录音」选择默认模式；也可以在风格页启用/停用模式并选择默认风格。

| 模式 | 适合场景 | 行为 |
| --- | --- | --- |
| Raw | 代码、会议原话、需要保留措辞 | 最小处理，尽量保持原始顺序 |
| Light | 日常聊天、快速记事 | 去掉明显重复和口癖，补标点，不改变事实 |
| Structured | 需求、任务、Prompt | 按主题、目标、约束整理成结构 |
| Formal | 邮件、工作沟通 | 语气更正式清楚，不凭空添加事实 |
| Translation | 双语沟通 | 按目标语言翻译后再插入 |

云端润色不可用时，应用会尽量保留原始转写；Raw 和可用的本地 ASR 可以在不调用
LLM 的情况下工作。

## 词库、风格包和翻译

### 词库

在词库中加入人名、产品名、缩写和领域术语。启用的词条会作为 ASR 热词或语义提示
发送给支持它们的 Provider，也会帮助后续润色。词库保存在本机，空词条不会生效。

### 风格包

内置 Raw、Light、Structured、Formal 风格包保存在本机，可离线查看、编辑和导入／导出。
**Light、Structured、Formal 的实际文字整理需要已配置且可用的文字服务**，与语音识别是两项能力；
仅下载本地识别模型不会获得离线整理。你可以复制内置风格，编辑系统提示、示例和标签，再设为默认。
远程 Marketplace 默认可能为空，这是本地优先策略，不代表本地风格坏了。只有配置
Listener Type 后端并完成相应登录后，远程上传、点赞等能力才会出现。

### 翻译

文字试译使用上文的独立文字工作区，不需要先录音。语音翻译则先使用已配置的语音识别服务转写，再按「工具 → 翻译」里明确选择的本机／云端方式和语言处理。普通听写仍保留原语言；文字试译不会改这些语音设置。

翻译页选择“禁用”时，翻译快捷键不会改变普通听写流程。实际全局快捷键与实体触发仍受操作系统和设备配置影响。翻译失败时请检查胶囊与历史里保留的原始转写，不把失败当作已成功翻译。

## 识别服务与网络

### 怎么估算自己的云费用

主页显示当前识别服务和文字服务，设置 → 提供商可看其配置，两者可能不同。「已配置」不代表余额或赠送额度；当前Type不展示合并账单或剩余信用额。

- 默认原文听写使用云识别时，费用来自音频识别服务。
- 润色、结构化、正式表达与主动选择的云端翻译，除识别外还可能产生文字服务费用。
- 选择本机中英翻译不产生翻译API费用；若先用云端识别音频，音频识别仍按该服务计费。
- 非原文/自定义风格的文字试用只提交文字，不提交音频；默认原文文字试用不请求云服务。

例如每天说5分钟、每月使用20天，就是100分钟音频。按当前提供商实际计费单位、费率及账户条款估算；文字服务还与输入、风格指令及返回长度有关，可用一条有代表性的短稿后到提供商账户查看实际用量。界面显示的响应耗时不是费用估算。49美元硬件价不包含这些用量；具体余额、费率和账单以对应提供商为准。


Listener Type 不内置开发者 API Key，云端调用使用你自己配置的凭据。可选 ASR
包括火山引擎流式、OpenAI-compatible 批量、百炼实时、本地 Qwen ASR（macOS）和
Windows Foundry Local；润色可使用 Ark、DeepSeek 或其他 OpenAI-compatible
服务，以「设置 → Provider」中的列表为准。

在「设置 → Provider」选择服务并填写 Key、Base URL、模型等字段；在「设置 → 权限」
确认网络状态。每个 Provider 都有 Network 选项：

- **Direct**：不走系统代理，适合国内 Provider 或系统代理指向已关闭端口时；
- **System**：使用系统 HTTP 代理及标准代理环境变量；
- **Custom**：填写完整 HTTP 代理 URL，例如 `http://127.0.0.1:7890`。

网络模式也用于流式 ASR WebSocket。应用不会把开发机的回环代理地址写进默认配置。
本地 ASR 需要先下载模型，首次加载会占用磁盘和内存；模型驻留时间可在高级设置中
调整。

## Listener 语音键盘

### 配对和输入

设备充电并开机后，在 Listener Type 中选择「开始配对」，再在 Windows 蓝牙列表中
选择 `listener`。连接成功后，先打开记事本测试。设备输入源选择 Listener BLE 时，
「检查连接」会验证 VKA1 音频服务；设备离线时按唤醒键/KEY4，再重试连接。

### 软件默认动作

在「设置 → 设备」选择 USB 有线或蓝牙无线，再选择目标设备。147 起，选择动作或开关后自动保存；
名称、模板和数字在编辑完成、移开光标后保存，拖动亮度滑块松开时保存，无需另外点击「写入」。
以“已保存到设备”的回读结果为准；失败保留修改，可点“重试保存”。连接、读取和切换设备不会自动写入默认值。
名称、灯光、电源、按键与旋钮各台独立保存在设备中；USB 和蓝牙读取同一份配置，换电脑仍保留。
本机“已保存的布局”仍是草稿库，只有明确选择“应用到当前设备”才会保存到键盘。
按键动作可包括桌面功能或快捷键；需要 Type 执行的动作仍需电脑端连接就绪。常用出厂动作如下：

| 控件 | 默认动作 |
| --- | --- |
| KEY1 单击 | 发送 Right Control |
| KEY2 单击 | 发送 Ctrl+C（复制） |
| KEY3 单击 | 发送 Ctrl+V（粘贴） |
| KEY4 单击 | 发送 Enter（回车） |
| EC11 单击 | 开始 / 停止录音 |
| EC11 旋转 | 电脑系统音量 |

KEY1–KEY4 还支持双击和长按映射；这两组在默认偏好中是禁用的，启用后可分别绑定
动作。EC11 的双击和长按由固件承担配对恢复/关机确认等硬件流程，桌面端不会把它们
当成普通 KEY 手势覆盖。

### 没有自定义映射时的底层入口

为了让设备在配置尚未同步时仍可被识别，固件会提供以下安全 HID fallback：

| 设备手势 | HID 入口 |
| --- | --- |
| KEY1 单/双/长 | F13 / F17 / F21 |
| KEY2 单/双/长 | F14 / F18 / F22 |
| KEY3 单/双/长 | F15 / F19 / F23 |
| KEY4 单/双/长 | F16 / F20 / F24 |
| EC11 单击 | Shift+F13 |

不要把 EC11 fallback 改成 F25；当前 Windows 热键支持矩阵没有 F25。物理 KEY3
不等于“永远录音键”：在当前软件默认映射中它是 Ctrl+V，录音推荐使用 EC11
单击或在设备设置中把某个手势改成 Dictation。

### 灯光和状态

设备灯区与屏幕胶囊共同表示状态：PWR（供电）、BLE（连接）、REC（录音）、AI
（处理）、OK（完成）、WARN（错误），另有按键灯、EC11 环灯和板框氛围灯。默认最大
亮度为：状态灯 50%、按键灯 80%、EC11 环灯 100%、板框灯 100%。亮度只改变可见度，
不改变麦克风音量、声纹分数或自动结束条件。低功耗时灯熄灭属于省电行为。

## 设备电源和低功耗

「设置 → 设备 → 电源时间」把插电和电池两种模式分开：

| 设置 | 默认 | 说明 |
| --- | ---: | --- |
| 插电允许低功耗 | 开启 | USB/充电/外部供电时允许进入低功耗 |
| 插电进入低功耗 | 3 分钟 | 无操作后进入 `CONNECTED_IDLE`/低功耗空闲 |
| 电池进入低功耗 | 1 分钟 | 拔电后无操作进入低功耗并灭灯 |
| 电池自动关机 | 10 分钟 | 电池长时间空闲后关机；插电不使用该计时器 |

时间范围是 0–1440 分钟，`0` 表示关闭该计时器。147 起编辑完成后自动保存，等待“已保存到设备”；
设备未连接或保存失败时，不能把屏幕上的草稿当成已经写入固件。电量读取不可用时界面
会显示“供电未知”，不要把未知状态当成 0%。

设备长按旋钮关机与软件退出是两件事。Windows 标题栏的 X 默认只隐藏到托盘；要
真正退出 Listener Type，请在托盘菜单选择「退出」，或运行：

```text
listener-type.exe --quit
```

「开机自启」是单独的登录启动开关；关闭它不会改变设备的自动关机策略。

## 剪贴板、历史和调试录音

- 「转写保留到剪贴板」默认开启，继续自动分段输入，结束后保留本次整段正文供手动粘贴；它优先于恢复旧剪贴板。流式输入的正文以已提交的分段为准，不在结束时重贴全文。粘贴路径会等待原输入框的只读回执再更新剪贴板；用户中途复制其他内容时取消回写。不支持回读的输入框保留安全粘贴载荷，完整正文仍可从历史复制。
- 「插入后恢复剪贴板」默认开启，仅 Windows/Linux 的粘贴路径适用；macOS 的键盘粘贴路径不恢复旧剪贴板。
- 「听写后自动发送」默认关闭；打开后可选 Enter 或 Ctrl+Enter。
- 历史、历史条数上限、上下文窗口和原始调试录音是独立设置。调试录音开启后会把
  WAV 留在本机，适合定位麦克风/BLE 问题，隐私敏感场景应关闭并及时清理。

## 语音提问与划词追问

Listener 已连接且识别、回答服务均已配置时，可以说“开始提问，一加一等于几？”。
问题卡片会在录音胶囊所在位置显示正在识别的问题；停说后自动收尾并请求回答。
如果仍在录音，也可以点“结束并提问”。“开始录音”继续用于听写，提问和回答不会
自动写入其它软件或剪贴板；需要时在卡片中主动复制。默认卡片为 360×240，可调整
大小，重新打开时保留本次已调整的大小。

也可以从「工具 → 划词追问」打开提问窗，点“开始提问”，对电脑麦克风说话，再点
“结束并提问”。这个按钮入口保留电脑麦克风来源，不会改动 Listener 的日用输入设置。

需要结合选中文字提问时，先选中其它应用中的文字，再按默认 `Ctrl/Cmd+Shift+;`
打开浮窗；确认所选内容后提问。选区会发送给当前配置的 LLM，超过 4000 字符时
只取开头 2000 和结尾 2000。浮窗支持多轮追问，按 `Esc` 或右上角关闭；关闭会
清除本轮对话。QA 默认不写入普通历史，是否保存由单独的历史开关控制。

语音识别和回答沿用已配置服务及其费用。回答会附带一条当前本地时间作为上下文，
仍应核对重要事实；配置存在不等于网络、鉴权或额度一定可用。

## Wayland 快捷键绑定

Wayland 下请在 GNOME/KDE/Hyprland/sway 的系统快捷键中绑定：

```text
listener-type --toggle-dictation
listener-type --toggle-qa
listener-type --cancel-dictation
```

其中 QA 和取消命令是可选的。应用会把第二个进程的参数转发给已经运行的主实例，
不会启动第二套录音状态。

## 故障排查

| 现象 | 处理 |
| --- | --- |
| 快捷键没有反应 | 检查「设置 → 权限」hook 状态；确认没有其它软件占用同一组合键；macOS 授权后完全重启应用 |
| 录音为空 | 检查麦克风权限、输入设备、ASR Key/模型；Listener BLE 则先检查连接和设备唤醒 |
| 只能复制不能自动插入 | 目标应用可能拒绝自动输入，直接从剪贴板粘贴；Windows 可检查非 TSF 兜底开关 |
| 国内 Provider 只有代理软件开着才成功 | 把该 Provider 的 Network 改为 Direct，或修正系统代理端口 |
| 自动唤醒不稳定 | 靠近设备、降低背景噪声、确认唤醒词正确；共享环境先录制声纹 |
| BLE 反复未连接 | 按 KEY4/唤醒键；仍失败时「设置 → 关于 → 设备恢复」，删除 Windows 中旧的 `listener` 后重新配对 |
| 灯熄灭 | 先看设备是否处于低功耗；低功耗灭灯是预期行为，不代表录音或固件损坏 |
| 关闭窗口后又出现 | X 只是隐藏到托盘；检查「开机自启」，需要结束进程请用托盘退出或 `--quit` |

仍无法定位时，在「设置 → 关于」导出诊断包，并记录版本、复现步骤、输入源和安装
包 SHA-256。诊断包用于连接、会话和设备状态定位，不包含 API Key 或转写正文；
已有保存的调试录音时，可能附带最近的调试音频样本；调试录音默认关闭。分享前检查诊断包和日志，不要把凭据粘贴到 issue 中。

## 隐私和产品边界

偏好、词库、风格包、历史和可选调试录音默认保存在本机。云端 ASR/LLM 是否接收
音频或文本取决于你选择的 Provider；应用不会内置开发者 Key。声纹模板只用于本机
主人判断，不是门禁、登录或身份认证。Listener Type 不是医疗设备、取证工具，也
不承诺多人同时说话时 100% 正确。
