# Listener 语音键盘开箱体验契约

定义从拆包装到第一次成功语音输入的内部测试体验路径。

## 目标用户

- 主要用户是对 AI 时代既好奇又焦虑的成年人和年轻成人。
- 使用场景是桌面娱乐、短句表达、语音触发的轻量创作和可控互动。
- 不是目标：3 岁以下儿童、需要医疗辅助的用户。

## 5 分钟 OOBE 目标

用户从拆包装到第一次成功语音输入，总耗时不超过 5 分钟。

| 步骤 | 预计时间 | 说明 |
|---|---:|---|
| 拆包装 | 30s | 取出设备、线缆、快速开始指南 |
| 充电/开机 | 1min | 如设备有电可直接跳过 |
| 安装软件 | 1-2min | 使用内部测试下载入口 |
| 配对 | 30s-1min | 蓝牙发现和连接 |
| 第一次试玩 | 30s | 按 EC11 旋钮 -> 说话 -> 得到文字 |

## 开箱路径

```text
拆包装 -> 开机 -> 安装软件 -> 开始配对 -> 连接成功 -> 按 EC11 旋钮 -> 说话 -> 停止 -> 看到文字
```

无 API Key 时走 Demo 或测试音频路径，不把 Demo 输出伪装成真实语音识别成功。

## 失败恢复路径

| 失败点 | 恢复方式 |
|---|---|
| 软件安装失败 | 核对 SHA256，改用便携 ZIP |
| 蓝牙配对失败 | 删除旧配对 -> 重启设备 -> 重新配对 |
| 无 API Key | 进入 Demo 模式先体验 |
| 网络不通 | 使用本地测试音频或稍后重试 |
| 识别失败 | 检查麦克风权限和服务商配置 -> 重试 -> 导出诊断包 |

## 隐私和诊断口径

- 录音会传到本机 Listener Type，再按用户配置交给 ASR 服务商处理。
- API Key 保存在本机配置或凭证存储中。
- 诊断包不包含录音、转写文本或 API Key。
- 当前内部文档不引用公开隐私政策 URL；公开发布前需要补齐正式隐私政策入口。

## 年龄与安全提示

- 建议年龄：13+。
- 小零件警告：不适合 3 岁以下儿童。
- 产品类别：计算机外围设备 / 语音输入设备。
- 不是玩具、医疗设备、心理治疗工具或儿童教育产品。

## 合规边界

| 不做 | 原因 |
|---|---|
| 宣称治疗效果 | 避免医疗器械监管 |
| 宣称教育提升 | 避免教育产品认证要求 |
| 针对 3 岁以下 | 小零件风险 |
| 收集儿童数据 | 儿童隐私风险 |
| 承诺 100% 识别准确率 | 避免误导 |
