# Listener 语音键盘开箱体验契约

定义从拆包装到第一次成功语音输入的 1.0.5 发布体验路径。

## 目标用户

- 主要用户是对 AI 时代既好奇又焦虑的成年人和年轻成人。
- 使用场景是桌面娱乐、短句表达、语音触发的轻量创作和可控互动。
- 不是目标：3 岁以下儿童、需要医疗辅助的用户。

## 5 分钟 OOBE 目标

用户从拆包装到第一次成功语音输入，总耗时不超过 5 分钟。

| 步骤 | 预计时间 | 说明 |
|---|---:|---|
| 拆包装 | 30s | 取出设备、线缆、快速开始指南 |
| 充电/开机 | 1min | 如设备有电可直接跳过 |
| 安装软件 | 1-2min | 使用 1.0.5 下载入口 |
| 配对 | 30s-1min | 蓝牙发现和连接 |
| 第一次试玩 | 30s | 按 EC11 旋钮或录音快捷键 -> 说话 -> 得到文字 |

## 开箱路径

```text
拆包装 -> 开机 -> 安装软件 -> 开始配对 -> 连接成功 -> 按 EC11 或录音快捷键 -> 说话 -> 停止 -> 看到文字
```

无 API Key 时引导用户配置本地 ASR 或补齐云端服务商凭据，不把占位内容伪装成真实语音识别成功。

## 失败恢复路径

| 失败点 | 恢复方式 |
|---|---|
| 软件安装失败 | 核对 SHA256，改用仓库根目录正式 MSI |
| 蓝牙配对失败 | 删除旧配对 -> 重启设备 -> 重新配对 |
| 无 API Key | 配置本地 ASR 或补齐云端服务商凭据 |
| 网络不通 | 使用本地测试音频或稍后重试 |
| 识别失败 | 检查麦克风权限和服务商配置 -> 重试 -> 导出诊断包 |

无工具恢复要求：

- 用户不需要安装 ESP-IDF、打开终端、看串口或输入 UUID。
- 桌面端路径是设置 -> 关于 -> 设备恢复：先停止当前录音/BLE 会话，再打开 Windows 蓝牙设置，删除 `listener`，回到录音设置里的 Listener BLE 重新配对。
- 这一步只覆盖 Windows/桌面端 pairing/session 恢复；设备端长按清配置由 firmware 步骤单独验收，不在桌面端文案里提前承诺。

## 用户可见状态

| 状态 | 用户理解 | 桌面端提示动作 |
|---|---|---|
| Ready | 设备可以用了 | 按 KEY3 开始录音 |
| Recording | 正在录音 | 说完再按 KEY3 停止 |
| Transferring | 音频正在传输 | 等待文字出现 |
| Error | 某一步失败 | 重试、切麦克风或本地 ASR，必要时导出诊断包 |
| Recovery | 需要恢复连接或重新配对 | 删除 `listener` 后重新配对 |

## 隐私和诊断口径

- 录音会传到本机 Listener Type，再按用户配置交给 ASR 服务商处理。
- API Key 保存在本机配置或凭证存储中。
- 诊断包不包含录音、转写文本或 API Key。
- 当前文档不引用公开隐私政策 URL；公开分发前需要补齐正式隐私政策入口。

## 年龄与安全提示

- 建议年龄：13+。
- 小零件警告：不适合 3 岁以下儿童。
- 产品类别：计算机外围设备 / 语音输入设备。
- 不是玩具、医疗设备、心理治疗工具或儿童教育产品。

## 合规边界

| 不做 | 原因 |
|---|---|
| 宣称治疗效果 | 避免医疗器械监管 |
| 宣称教育提升 | 避免教育产品认证要求 |
| 针对 3 岁以下 | 小零件风险 |
| 收集儿童数据 | 儿童隐私风险 |
| 承诺 100% 识别准确率 | 避免误导 |
