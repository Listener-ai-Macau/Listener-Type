# Listener 1.0.5 用户体验优化方案

> 日期：2026-08-05  
> 基线：1.0.4（预览顺滑已 owner 验收，`smooth_preview_*` / LST-REC-033 防回退）  
> 目标版本命名：按 owner 说法写作 **1.0.5**（体验向次版本；若发版号改为 1.0.5 可整份替换版本号，内容不变）  
> 输入：1.0.4 实机日志与验收、业界听写/语音产品公开做法

---

## 1. 一句话定位

**1.0.4**：把「说得上、出得顺、1 秒收得住、别人不拖、不空字」做稳。  
**1.0.5**：在不破坏上述合同的前提下，把体验从「能用」推到「像成熟听写产品一样省心」——更跟手、更少打断心流、更少二次操作。

---

## 2. 1.0.4 基线（已冻结，1.0.5 不得回退）

| 能力 | 合同/门 |
|---|---|
| 顺滑 live 预览 + burst ≤160ms | LST-REC-033 / `smooth_preview_*` |
| 本人 1.0s 自动结束 | `target_speaker_end_1000ms` |
| 别人说话不拖结束 | NonTarget 不推进本人时钟 |
| 空 final / two_pass_empty 不抹字 | session ledger |
| 胶囊后 body wait ≤700ms | `body_initial_wait_700ms` |
| 唤醒 800ms 起确认 | `local_confirmation_800ms` |

1.0.5 任何优化必须先跑这些门；**禁止**用拉长结束时间换「完整度」来冒充体验升级。

---

## 3. 业界成熟产品怎么做（可借鉴点）

### 3.1 桌面听写（Wispr Flow / Superwhisper 一类）

公开卖点与用户反馈的共性：

| 做法 | 对用户的价值 | Listener 现状 |
|---|---|---|
| **全应用插入、不切模式** | 键盘与语音同一输入框，不打断心流 | 已有粘贴/插入路径 |
| **Live 流式出字**（非说完再转） | 跟手、可边说边改 | 1.0.4 已强 |
| **口语清理 / 润色可选** | 去嗯啊、补标点、按场景语气 | 有润色与去语气词，可产品化分层 |
| **小声/耳语模式** | 办公室可用 | 有动态电平预处理，未产品化「模式」 |
| **忠实转写 vs AI 改写可切换** | 专业用户怕被改词 | 可明确两档 |
| **不因思考停顿频繁打断** | 用户原话：不要在组织语言时被 dictation 掐断 | 1s 结束偏跟手，长想仍可能分段 |

参考方向：Flow 强调 natural speech、跨应用、不打断 articulation；Superwhisper 强调「Voice to Text 忠实」与「AI 模式可选」。

### 3.2 系统听写（Apple Dictation）

| 做法 | 利 | 弊（用户吐槽） | Listener 启示 |
|---|---|---|---|
| 自动标点 | 省事 | 乱逗号、断句不稳 | 自动标点要**可关**、可分级 |
| 长静音结束会话（约 30s 量级） | 长文不易被掐 | 想词短停也会结束；不可配置 | 硬件键鼠听写不宜照搬 30s；可做**长文模式可选** |
| 系统级任意输入框 | 零学习成本 | 质量与清理弱 | 继续强化「焦点字段一说就进」 |

### 3.3 智能助手（小爱等）

| 做法 | 对 Listener 可迁移部分 |
|---|---|
| 唤醒短、反馈明确 | 灯 + 胶囊状态要「一眼懂」 |
| 全场景协同 / 主动智能 | 1.0.5 可选：场景热词、应用感知语气（勿做过度主动） |
| 多人/噪声仍是行业难点 | 继续「本人跟住 + 别人不拖」；深分离仍可后置 |

### 3.4 业界延迟与端点共识（工程）

- **对话机器人**：尾静音常 0.3～0.8s（要快、易掐）。  
- **听写**：0.8～2s 更常见；过短截自然停顿，过长显拖。  
- Listener 1.0.4 选 **本人 1.0s** 已对齐「跟手听写」；1.0.5 应用 **模式** 解决长文，而不是全局改默认。

## 4. 差距：1.0.4 → 成熟听写体验

| 体验维度 | 成熟产品 | 1.0.4 | 1.0.5 机会 |
|---|---|---|---|
| 出字跟手 | 流式 + 不闪 | 已较好 | 防回退；压唤醒→胶囊偶发尖刺 |
| 收尾跟手 | 明确「在处理」 | 1s 结束 OK，UI 反馈可更早 | 结束瞬间状态机 |
| 启动跟手 | 唤醒即听 | 胶囊快，首字仍受云端 | 体感「已在听」+ 首字指标 |
| 不打断心流 | 长想不乱掐 / 可续说 | 1s 想词可能分段 | **听写模式**：标准 / 长文 |
| 标点与润色 | 自动标点 + 可选 AI | 有能力未体验化 | 设置与默认策略 |
| 嘈杂/小声 | 耳语、噪声门 | 有预处理 | 模式与提示 |
| 纠错 | 语音改上一句 | 弱 | 轻量命令 |
| 可信与可控 | 忠实/润色分档 | 部分有 | 产品表达清晰 |
| 硬件一体感 | 灯/触/键一致 | 有灯与键 | 状态灯与胶囊语义对齐 |

## 5. 1.0.5 优化方案（建议范围）

### 主题 A — 时延与状态反馈（体验主线，优先）

| ID | 优化项 | 用户感知 | 建议指标（机器可判） |
|---|---|---|---|
| A1 | 唤醒→胶囊 p95 ≤1200ms，ceiling ≤1500ms | 「一喊就亮」 | 日志 `wake_to_capsule_request_ms` |
| A2 | 胶囊出现即明确「正在听」态（即使尚无字） | 不怀疑没启动 | 状态序列 + 截图/时间线 |
| A3 | 静音达阈 **立即** 切 Transcribing/处理中，不干等 final | 说完不「悬」 | stop→Transcribing ≤150ms |
| A4 | 说完→可粘贴/完成 p95 可观测并压尖刺 | 整段跟手 | stop→Done/Polishing 耗时分布 |
| A5 | 保持 1.0s 本人结束；禁止默认改回 1.5s+ | 跟手合同 | 防回退门 |

### 主题 B — 模式与心流（成熟听写的关键差异化）

| ID | 优化项 | 用户感知 | 建议做法 |
|---|---|---|---|
| B1 | **标准听写**（默认）：1.0s 本人结束 | 短句、聊天、填表 | 现状默认 |
| B2 | **长文听写**（可选）：本人静音 2.0～2.5s 或「按键结束」 | 写邮件/长段不爱被掐 | 设置一项，默认关 |
| B3 | **续说**：结束后 N 秒内再开口可续同一条（可选） | 被掐后不整段重来 | 需严格边界防误续 |
| B4 | 语气词清理 / 润色：**默认轻量、可关** | 像 Flow 干净，又像 Superwhisper 可控 | 两档：忠实 / 整洁 |

### 主题 C — 预览与插入质量（在防回退之上增强）

| ID | 优化项 | 用户感知 |
|---|---|---|
| C1 | 自动标点策略可配置（开/关/仅句末） | 少乱逗号 |
| C2 | 插入失败时一键「仍在剪贴板 + 明确提示」 | 不丢字 |
| C3 | 热词/专有名词更稳（应用场景词典） | 专业词少错 |
| C4 | 预览与最终字差最小化（少「最后整段改脸」） | 信任感 |

### 主题 D — 噪声与多人（体验层，非 1.0.5 深分离）

| ID | 优化项 | 用户感知 |
|---|---|---|
| D1 | 设置文案说清：未录声纹=大家可唤醒；录了=仅本人 | 预期一致 |
| D2 | 「嘈杂环境」提示：靠近说 / 录声纹 | 少误唤醒挫败 |
| D3 | 别人说话：继续不拖结束、不进预览（强化验收场景） | 办公室可用 |
| D4 | 深说话人分离、会议转写 | **不进 1.0.5 必做**；可列 1.2 |

### 主题 E — 硬件一体与灯效语义

| ID | 优化项 | 用户感知 |
|---|---|---|
| E1 | 录音中 / 处理中 / 完成 / 错误 灯效与胶囊状态严格对齐 | 不看屏幕也懂 |
| E2 | 双击蓝牙、OTA、重命名等非听写路径零回退 | 整机可信 |
| E3 | 低电/断连时听写路径明确失败原因 | 不「没反应」 |

### 主题 F — 可观测与防回退（工程体验）

| ID | 优化项 |
|---|---|
| F1 | 听写 UX dashboard 字段：wake_to_capsule、first_body_char、stop_to_transcribing、stop_to_done |
| F2 | 1.0.5 继续扩展 `verify-listener-*-protected-contracts` |
| F3 | 短 owner 手测清单：唤醒→预览→1s 收→别人说话不拖→空 final 不丢 |

## 6. 建议实施分期

### P0（1.0.5 必做，约 1 个迭代）

1. **A1～A4**：时延尖刺 + 状态反馈（最大体感提升）  
2. **B1+B2**：标准 / 长文两种结束策略（解决 1s vs 想词 的根本矛盾）  
3. **F1+F3**：指标与手测清单  
4. 全量跑现有 `smooth_preview_*` / 1s 结束门  

### P1（同版本有余力或 1.0.5.x）

- B4 忠实/整洁两档  
- C1 自动标点可关  
- D1～D3 预期与嘈杂提示  
- E1 灯效对齐  

### P2（明确后置）

- B3 续说（易误触，要单独 Goal）  
- D4 会议级分离  
- 大模型实时改写默认开启（隐私与「被改词」风险）  

---

## 7. 明确不做（1.0.5）

- 默认结束改回 1.5s/2s  
- 拆掉 optimistic 预览或拉长 burst 预算破坏顺滑合同  
- 用「多人质量」绑架听写主路径  
- 无指标的纯文案/视觉大改却不动链路  

---

## 8. 成功标准（版本级）

机器：

- 既有 1.0.4 防回退门 100% PASS  
- A1：wake_to_capsule p95 ≤1200ms（装包日志样本 ≥N 次）  
- A3：stop→Transcribing ≤150ms  
- B2：长文模式 endpoint 配置与测试合同存在且默认可关  

人工（owner）：

- 短句听写：跟手、预览顺、1s 收顺  
- 长段口述：开长文模式后明显少被掐  
- 办公室：别人说话不拖、不乱出别人字

## 9. 与 1.0.4 / 后续版本关系

```text
1.0.4  ── 稳定听写核心 + 顺滑预览防回退
   │
1.0.5  ── 体验升级：时延反馈 + 模式（标准/长文）+ 可控润色/标点
   │
1.1+   ── 深多人/会议、续说、场景主动智能（可选）
```

## 10. 结论与建议 owner 决策

**最值得在 1.0.5 做的三件事：**

1. **状态与时延**（启动、结束反馈跟手）  
2. **标准 / 长文两种听写模式**（业界用「模式」解决 1s vs 想词，而不是全局加时间）  
3. **润色/标点/忠实可配置**（对齐 Flow 干净 + Superwhisper 可控）

**1.0.4 已验收的预览顺滑：只防回退，不重做。**

若认可本方案，下一步可开 1.0.5 Goal，把 P0 表写成可测技术指标并开工。
