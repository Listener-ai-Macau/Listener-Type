# 产品优先级（锁）

同时满分做不到。按这个权衡，不再跟症状左右拧。

1. **保住唤醒** 优先于少误唤醒  
2. **停不了** 优先于停太早（宁可按一下停，不要说到一半被掐）  
3. **不吞你的字** 优先于抗干扰  
4. **预览顺**（自动结束打最后预览）  
5. 其余后做  

结束钟用「胶囊字还在涨」的墙钟，不用会冻住的音频空隙。  
有词（ExactStart / PresentLater / 关键词）即使第一次声纹没对上也开录。  
已显示的字不回撤。
低优先 G：确认是旁人的新尾巴不加进去，但绝不回改已显示的字。

手动右 Ctrl / EC11 对照不许变差。
