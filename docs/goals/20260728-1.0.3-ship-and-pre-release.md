# Goal：1.0.3 整理、验收、发布与发布前测试

> Active Goal。完成前不得宣称「可对外安装包已与当前树对齐」。

## 目标

在 **当前工作树**（含 dual-lane OTA reorder / host dual WWR / preflight 延迟修复）上：

1. 整理 1.0.3 版本身份与相对已挂 `v1.0.3` 的增量；
2. 跑机器发布门禁与关键真机探针（验收）；
3. 用当前树 **重打** Type MSI + Firmware OTA，落到 Denzic 根标准文件名；
4. root artifact 校验；有条件则本机同版本安装 smoke；
5. 写发布前全量证据与 **GO / NO-GO**。

## 人工边界

- 不自动要求 owner 弹窗 human-review；机器门禁先闭环。
- Authenticode：本机无证书则写「未签名 / SmartScreen 风险」。
- GitHub Release：可更新 `v1.0.3` 资产；无权限则写阻塞。
- OTA bulk 目标 50 KB/s **不作为 1.0.3 阻断**；当前 dual ~46 KB/s + 0 recovery 为已知水位。
