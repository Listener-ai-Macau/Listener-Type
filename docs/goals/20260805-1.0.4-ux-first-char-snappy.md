# Goal：Listener 1.0.4 听写体验跟手优化

> 状态：进行中 / 预览顺滑已 owner 确认并上防回退门（LST-REC-033）；首字体验可继续爬坡
> 合同：本文件 + LST-REC-032 + LST-REC-033
> 产品：Listener Type 1.0.4
> 创建：2026-08-05

## 目标

在**保持本人 1.0s 自动结束、别人说话不拖结束、空 final 不抹字**的前提下，优化 1.0.4 听写「启动跟手感」：用户说完唤醒词后，胶囊尽快出现、正文第一字尽快上屏、说完后收尾仍跟手。

## 技术指标

| 功能 | 成功状态 | 技术阈值 | 自动判定 |
|---|---|---|---|
| 唤醒→胶囊 | 非 idle 下说唤醒词后尽快出现 Recording 胶囊 | `wake_to_capsule_request_ms` 目标 ≤1200；ceiling ≤1500 | 日志解析 PASS；超 ceiling FAIL |
| 胶囊后首字 | 用户连续说正文时，尽快出现非空 body 预览 | 可见胶囊后 **body wait 上限 ≤700ms**；首字可由 partial 立即结束 wait | 源码合同 `EMBEDDED_AUTOMATIC_BODY_INITIAL_WAIT_MS == 700` + 单元测试；安装日志首字耗时归档 |
| 本人自动结束 | 本人停说后约 1s 结束 | `target_speaker_inactive_1000ms`；他人不刷新本人时钟 | 合同 + 既有 endpoint / NonTarget 测试 PASS |
| 空 final | 有预览则不得变「没有识别到语音」 | two_pass_empty / 空 final 用会话账本 | 既有 volcengine 测试 PASS |
| 胶囊预览稳定 | level-only / 空 payload 不抹已有正文 | 同 session Recording 无 message 时保留预览 | 前端 `shouldPreserveMessageWithoutPayload` 行为 + 构建 PASS |

## 机器闭环

- **输入/触发**：装最新 MSI；非 idle；说唤醒词 + 连续说一句正文后停说。
- **可观察结果**：`listener-type.log` 中 `wake_to_capsule_request_ms`、`automatic body wait`、`automatic body started`、首条非空 `message=`、`target_speaker_inactive_1000ms`、final 非空。
- **自动判定**：Rust endpoint/volcengine 相关测试 PASS；`verify-listener-1.0.4-protected-contracts.mjs` PASS；MSI 安装载荷哈希一致；证据落盘 `.artifacts/listener-1.0.4-ux-first-char-snappy-*/`。
- **FAIL**：回修后重装再测，不口头 PASS。

## 人工边界

机器 PASS 后，owner 体感：唤醒→胶囊→首字是否更跟手；说完 1s 收尾是否可接受；别人说话是否拖结束。FAIL 回修。

## 排除

- 不重开 1.5s 默认结束。
- 不调声纹阈值大改、不做 1.0.5 会议级分离。
- 不改 idle 不唤醒边界。
