## 1. 目标

在不破坏 1.0.4 听写合同的前提下，改善用户录音体验：

1. **标准 / 长文听写模式**：默认仍 1.0s 本人结束；可选长文 2.0s。  
2. **结束反馈更快**：静音达阈后立即切 Transcribing 并保留预览，不干等 final。  
3. **启动可感**：胶囊空录音态显示「正在听」；处理中文案本地化「处理中…」。  
4. **自动化与可控**：录音自动化区澄清自动起/停、长文、忠实/整洁风格与嘈杂提示。  
5. **版本身份**：产品号 1.0.5，正式 MSI 安装验收。
