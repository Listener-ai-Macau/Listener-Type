# Goal：Listener 1.0.5 多人语音隔离（只识别本人）

> 日期：2026-08-05  
> 版本：`1.0.5`  
> 状态：**机器闭环 PASS / 已装包**；owner 手测确认「可以排除掉别人说的话」  


> 基线：1.0.4 听写合同（1s 结束、空 final 不抹字、顺滑预览）不得回退  
> 输入：owner「多人语音会话还是没修好，要隔离别人的对话，只识别本人」+ 业界 Target-Speaker ASR 做法

## 1. 目标一句话

唤醒开启听写后，在多人环境中**只把本人说的字**上到预览与最终插入；旁人插话不进字、不拖本人结束时钟、不污染会话账本。

## 2. 业界对齐（工程可落地部分）

| 路线 | 业界做法 | 1.0.5 采用 |
|---|---|---|
| Target-Speaker ASR | 用目标说话人 embedding 条件化 ASR（Whisper/TS-ASR、DiCoW 等） | 后置；云端未暴露完整 TS 接口时不做重训 |
| 流式 diarization + 过滤 | 实时 speaker label，只保留目标 id 文本（AssemblyAI 等） | **采用**：火山 utterances 的 speaker + 本地证据二次闸 |
| 本地 speaker verification | 会话内 embedding 对比唤醒锚点/声纹 | **采用并加硬**：Target 才进账本；NonTarget 冻结 |
| 声纹 enroll | 持久 owner 档案，避免 open gate | 保留；未 enroll 仍用唤醒锚点 ephemeral，隔离合同仍生效 |

原则：**双闸（云端说话人 + 本地 embedding）取交集**；宁可漏旁人尾音，不可把旁人整句贴进输入框。

## 3. 技术指标

| 功能 | 成功状态 | 技术阈值 | 自动判定 |
|---|---|---|---|
| 旁人不定式 stream 不进 optimistic | 最新本地样本 NonTarget 时，optimistic 文本 = Target 过滤文本 | 不包含旁人 tail | 单测 `room_speech_raw_stream_*` PASS |
| 旁人句不进会话账本 | NonTarget 窗口内 unstable/稳定旁人句不 commit best | best 不随旁人增长 | 单测 + 契约门 |
| 结束时钟不被旁人刷新 | NonTarget / 非 Target 预览不 refresh local_target | 仅 Target 分类刷新 | 单测 + 源码合同 |
| Final 不上污染字 | local tracking 且曾出现 NonTarget 时，final 不取更长 optimistic | final ≤ 过滤本人字 | 单测 `isolation_final_rejects_polluted_optimistic` PASS |
| local 证据严格多数 | utterance 窗口内 NonTarget 票 ≥ Target 票则拒收 | `target_votes > non_target_votes` | 单测 |
| 1.0.4 防回退 | 1s 结束、空 final 账本、burst 预览 | 既有门 | `verify-listener-1.0.5-protected-contracts.mjs` PASS |

## 4. 机器闭环

- 输入：合成/fixture 帧（owner 稳定句 + 旁人 stream 句 + NonTarget evidence）走 `filter_result_to_target_speaker_with_local_evidence` / handle_frame 单测。  
- 可观察：filtered text、optimistic text、best_transcript、final 选择。  
- 失败：回修后重跑单测与契约门；装 MSI 后 owner 手测。

## 5. 人工边界

装最新 1.0.5 后：唤醒 → 本人一句 → 旁人插话 → 本人停。  
期望：上屏/预览主要是本人；旁人整句不应进入。  
FAIL 回修。

## 6. 排除

- 不实现完整 TS-ASR 重训 / 服务端换供应商  
- 不把默认结束改回 2s  
- 不把「必须 enroll 声纹」写成硬门槛（未 enroll 仍靠唤醒锚点隔离）
